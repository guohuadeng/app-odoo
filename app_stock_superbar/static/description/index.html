功能概述 / Overview

库存超级搜索栏（Superbar）通过库存位置的父子树结构，让您在列表、看板、透视和图表视图中快速导航和搜索库存相关数据，包括调拨单、批次、移动和库存批次等。

Stock Superbar uses parent children tree of stock locations to navigate and search inventory data across list, kanban, pivot and graph views including picking, batch, move and lot.
