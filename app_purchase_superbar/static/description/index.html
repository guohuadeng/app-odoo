Purchase Superbar Navigator

Browse Purchase Orders by Vendor with Tree Navigator

Navigate purchase data quickly via tree structure in list, kanban, pivot and graph views

Odoo 18 Enterprise & Community Multi-Company Multi-Language

Overview

Add search panel (Superbar) to purchase orders, request quotations and supplier info for tree navigation by vendor, state and invoice status. Supports list, kanban, pivot and graph views to greatly improve purchase data lookup efficiency.

Complete Feature List

  • Easy to show parent-children tree for list, kanban, pivot, graph views
  • Product navigate by category or type
  • POS navigate by category or store
  • Account chart navigate by type
  • Contacts navigate by company
  • Sale order navigate by partner and channel
  • Purchase order navigate by partner
  • HR employee navigate by department
  • Easy to customize, you can use it anywhere in Odoo

Vendor Tree Navigation

Partner-based search panel

State and invoice status filter
