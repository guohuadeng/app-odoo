功能概述 / Overview

为采购订单、采购询价单和供应商信息添加搜索面板（Superbar），通过供应商、状态、开票状态等维度进行树状导航。支持列表、看板、透视表和图表视图，大幅提升采购数据的查找效率。

Add search panel (Superbar) to purchase orders, request quotations and supplier info for tree navigation by vendor, state and invoice status. Supports list, kanban, pivot and graph views to greatly improve purchase data lookup efficiency.
