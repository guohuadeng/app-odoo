功能概述 / Overview

本模块为 Odoo 技术设置（菜单、视图、字段、动作、报表、服务端动作、附件、默认值、权限、约束、用户）提供 Superbar 树状导航。按分类树快速浏览和搜索各项配置，支持列表/看板/透视表/图表视图。

This module provides Superbar tree navigator for Odoo technical settings. Navigate menus, views, fields, actions, reports, server actions, attachments, defaults, access rights, constraints, users by category tree with list/kanban/pivot/graph views.
