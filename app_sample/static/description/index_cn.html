功能概述

一个完整的 Odoo 模块开发模板，包含 manifest、模型、视图、控制器、报表、动作、菜单等所有文件类型的示例代码，以及 170+ Widget 清单和常用用法指南。

核心亮点

一站式 Odoo 开发模板

1. 完整示例模块

包含完整的 Odoo 模块代码、视图和数据示例，遵循 Odoo 规范

Manifest File

包含所有字段的清单示例，安装 XML 和 CSV 文件

3. 模型示例

包含新模型和继承模型的 Python 示例文件

4. 视图示例

包含列表、看板、表单和搜索视图的 XML 示例

5. 控制器示例

网站数据发布和 API 接口开发示例，含 Portal 继承

6. 报表示例

Widget Guide

170+ Widget 使用清单和常用 Widget 用法指南

8. 开发教程

快速访问在线中英文 Odoo 开发教程，国内快速访问
