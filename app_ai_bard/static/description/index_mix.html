功能概述 / Overview

本模块为 Odoo AI Center 添加 Google Gemini（原 Bard）AI 支持。集成多种 AI 机器人（Google Gemini、Azure AI、ChatGPT 4/3.5/3、DALL-E），支持将 AI 绑定到用户进行对话或群聊、黑白名单控制、新用户体验时间设置、AI 响应评价训练、同步/异步模式切换、敏感词过滤。

This module adds Google Gemini (formerly Bard) AI support to Odoo AI Center. Integrates multiple AI robots (Google Gemini, Azure AI, ChatGPT 4/3.5/3, DALL-E). Supports AI binding to users for chat or group chat, whitelist/blacklist, demo time setup, evaluation training, sync/async mode, sensitive words filter.

    Multi ChatGPT OpenAI robot Connector. Chat and train.
  • 2. 多AI支持：Google Bard AI、Azure AI、ChatGPT 4、3.5 Turbo、3 Davinci、2 Code、DALL-E图片
    Multi AI support including Google Bard AI, Azure AI, ChatGPT 4, 3.5 Turbo, 3 Davinci, 2 Code, DALL-E Image.
  • 3. 绑定ChatGPT API到用户，可对话机器人用户或使用AI频道群聊
    Bind ChatGPT API to user for robot chat or group AI channel.
  • 4. ChatGPT白名单与黑名单
    White and black list for ChatGPT.

    Setup demo chat time for every new user.

    Easy start and stop ChatGPT.
  • 7. 评价AI机器人回复，优化响应质量（训练）
    Evaluation the AI robot to make better response. This training.
  • 8. 连接Microsoft Azure OpenAI服务
    API support for Microsoft Azure OpenAI Service.
  • 9. 支持同步或异步AI响应模式
    Set synchronous or asynchronous mode for AI response.
  • 10. 敏感词过滤设置
    Filter sensitive words setup.
