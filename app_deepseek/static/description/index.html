  • 1. Deepseek Ai支持-多Ai机器人连接器，聊天与训练
    Deepseek AI support for Multi Ai robot Connector. Ai Chat, character setup and train.

    Multi Ai support including Google Bard Ai, Azure Ai, Chatgpt 4, Chatgpt 3.5 Turbo, Chatgpt 3 Davinci, Chatgpt 2 Code Optimized, Dall-E Image.

  • 4. ChatGPT白名单和黑名单管理
    White and black List for ChatGpt.
  • 5. 为新用户设置演示聊天时长
    Setup Demo Chat time for every new user.

    Easy Start and Stop ChatGpt.
  • 7. 评估AI机器人回复质量，通过训练持续改进
    Evaluation the ai robot to make better response. This training.
  • 8. Microsoft Azure OpenAI服务API对接支持
    Add api support Connect the Microsoft Azure OpenAI Service.
  • 9. 支持同步或异步模式获取AI回复
    Can set Synchronous or Asynchronous mode for Ai response.
  • 10. 敏感词过滤设置
    Filter Sensitive Words Setup.
