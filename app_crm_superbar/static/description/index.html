功能概述 / Overview

为 Odoo CRM 模块提供强大的侧边栏超级导航功能。在商机视图中按阶段和团队筛选，在线索视图中按营销活动、媒介和来源筛选，并在 CRM 报表中按多个维度透视和图表分析。

Provides a powerful sidebar superbar for the Odoo CRM module. Filter opportunities by stage and team, leads by campaign, medium and source, with pivot and graph report navigation.
