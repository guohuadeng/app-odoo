使用方法：本应用需要额外模块，价格已包含

1. 购买并安装 zTree 控件 Click to download.

2. 购买并安装 app_web_superbar 重要！安装后需重启 Odoo。

3. 轻松使用超级导航

列表视图中显示超级导航。

看板视图中显示超级导航。

透视表中显示超级导航。

图表视图中显示超级导航。

点击切换显示或隐藏超级导航。

勾选复选框控制是否显示子节点数据。

按 Ctrl（Windows）/ Cmd（Mac）多选节点

设置多字段搜索或过滤

设置超级导航位置，左侧或右侧。

4. 如需定制，使用以下参数配置控件（定制支持需额外付费）：

  • 在搜索视图 XML 中编写 <superbar> 标签
  • position：位置，可选 [left, right]
  • view_mode：视图模式，可选 [kanban, tree, pivot, graph]
  • parent_key：父子关系的键字段名，留空自动识别。
  • level：树初始化时展开的层级数，默认 2
  • limit：zTree 显示的记录数，默认 16
  • order：排序字段名
  • domain：数据过滤域，如 [[('is_company', '=', 1)]]
