功能概述

在库存调拨单的 one2many 行视图中，点击"批量添加"按钮，即可弹出产品选择窗口，支持过滤、分组后多选添加产品到调拨单。

核心亮点

快速高效的批量操作

1. 一键添加

点击"批量添加"按钮即可打开产品选择窗口

2. 过滤分组

支持对产品进行过滤和分组后批量选择添加

3. 通用配置

通过 XML 配置可为任何 one2many 字段启用批量添加

通用特性

多语言与多公司

完整的多语言翻译支持，适配全球化企业部署。原生多公司架构，数据严格隔离。

全版本兼容

支持 Odoo 19, 18, 17, 16, 15, 14, 13, 12，EE/CE/.SH，兼容企业版、社区版及在线 SaaS。

代码完全开源

基于 LGPL-3 协议开源，代码透明可审计，支持二次开发与定制。
