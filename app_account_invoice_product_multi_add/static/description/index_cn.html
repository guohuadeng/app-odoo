功能概述

本模块为客户发票（Customer Invoice）和供应商账单（Vendor Bill）提供一键批量添加产品功能。点击「Multi Add Items」按钮打开弹窗，按分类过滤、分组产品，多选后一次添加到发票明细行。

适用于客户发票、供应商账单，以及通过 XML 配置的任意 one2many 明细行。
