报销树状导航 Pro

在费用报销增强之上，按部门与分析账户浏览报销单

配合费用报销增强，把部门与分析账户字段带进报销单，再用树状导航快速核对。

Odoo 20企业版与社区版多公司多语言

功能概述

Pro 版在标准树状导航的基础上依赖 app_hr_expense_pro（费用报销增强），报销单具备部门与分析账户字段，可以直接按组织或项目归集。树状栏同样支持列表、看板、透视表与图表视图，支持多选、子节点联动与多字段搜索，适合需要按成本中心核算的企业。

核心亮点

在费用报销增强之上，按部门与分析账户浏览报销单

1. 部门树

按部门父子层级浏览报销单

2. 分析账户树

按分析账户或项目归集费用

3. 费用增强字段

依赖 app_hr_expense_pro 的部门与分账户字段

4. 多视图

列表、看板、透视表、图表均可用

5. 多选与子节点

Ctrl/Cmd 多选，勾选包含子节点

6. 侧栏切换

树状栏可放左侧或右侧

完整功能列表

本模块包含的全部功能

  • 1. 按部门父子层级浏览费用报销单
  • 2. 按分析账户归集与筛选报销
  • 3. 依赖费用报销增强，报销单带部门与分析账户字段
  • 4. 列表、看板、透视表、图表视图均可使用
  • 5. Ctrl/Cmd 多选树节点，勾选包含子节点
  • 6. 多字段搜索与过滤
  • 7. 树状侧栏可切换左右位置
