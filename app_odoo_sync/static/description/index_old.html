Odoo Instance Data Sync (18 → 20)

Pull partners, companies and users from a remote Odoo 18 instance, read-only.

The Odoo 20 database is the target and pulls data from an Odoo 18 source over RPC. The adapter only allows read methods: any write method is rejected before a network call.

Highlights

  • Read-only XML-RPC adapter with whitelist, timeout, retry and rate limit.
  • Matching by xml_id, record map and business key, so repeated runs never duplicate records.
  • ID and xml_id preservation with conflict detection instead of silent overwrite.
  • Topological ordering with depends_on, two-phase parent_id import.
  • Incremental waterline (write_date + id) with a 30 second overlap window.
  • Dry run, per-record logs, retry queue and reconciliation checks.

Scope of the first phase

res.company, res.partner (with categories, bank accounts and addresses) and res.users (internal and portal), plus oauth.users identity bindings. Tokens, passwords, attachments and business documents are not migrated.
