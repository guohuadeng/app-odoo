功能概述

销售订单高级搜索栏专业版（Superbar Pro）提供即时和延迟两种搜索模式，支持在列表、看板、透视和图表视图中通过父子树结构快速导航和搜索销售订单数据。

核心亮点

专业版高级功能一览

1. 即时搜索

即时模式，点击即刻搜索，快速响应

2. 延迟搜索

延迟模式，设置筛选条件后再搜索，适合大数据量场景

3. 父子树导航

通过客户和渠道的父子树结构快速定位销售订单

4. 多视图支持

支持列表、看板、透视和图表视图中显示搜索侧栏

5. 移动端适配

移动端自适应响应式视图，优化大屏幕高清显示

6. 易于定制

通过简单 XML 配置即可在任何 Odoo 模块中使用

通用特性

多语言与多公司

完整的多语言翻译支持，适配全球化企业部署。原生多公司架构，数据严格隔离。

全版本兼容

支持 Odoo 19, 18, 17, 16, 15, 14, 13, 12，EE/CE/.SH，兼容企业版、社区版及在线 SaaS。

代码完全开源

基于 LGPL-3 协议开源，代码透明可审计，支持二次开发与定制。
