功能概述 / Overview

Contacts Superbar Pro 是通讯录超级导航的专业增强版。在继承标准版全部功能的基础上，新增按公司类型（公司/个人）筛选和创建日期范围搜索，满足更精细化的联系人管理需求。

Contacts Superbar Pro is the enhanced version of the contacts navigation superbar. It inherits all standard features and adds company type filter and date range search for more precise contact management.
