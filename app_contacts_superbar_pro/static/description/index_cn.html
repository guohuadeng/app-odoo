功能概述

Contacts Superbar Pro 是通讯录超级导航的专业增强版。在继承标准版全部功能的基础上，新增按公司类型（公司/个人）筛选和创建日期范围搜索，满足更精细化的联系人管理需求。

需以 app_contacts_superbar 作为基础模块。

核心亮点

标准功能 + 专业增强

1. 公司类型筛选

Company vs Individual

按公司类型（公司/个人）快速分类筛选

2. 日期范围搜索

Create Date Filter

按创建日期范围筛选联系人

3. 类别多选

Partner Category with Counters

按合作伙伴类别多选筛选并显示计数

4. 行业分类

Industry Type Filter

按行业类型快速筛选联系人

5. 多公司分组

Company Grouping

多公司分组筛选，适配企业级部署

6. 多视图支持

List, Kanban, Pivot, Graph

在所有视图中使用侧边栏导航
