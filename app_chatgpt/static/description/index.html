功能概述 / Overview

本模块是 Odoo AI 服务中心，支持集成多种 AI 模型（ChatGPT-4o、GPT-4、GPT-3.5、DeepSeek、阿里通义千问、百度文心、Azure OpenAI）。通过 Odoo 讨论频道直接与 AI 机器人对话，支持多机器人管理、用户绑定、黑白名单、评价训练、同步/异步模式、敏感词过滤。

Odoo AI Center supporting ChatGPT-4o, GPT-4, GPT-3.5, DeepSeek, Alibaba Qwen, Baidu AI, Azure OpenAI. Chat with AI robots via Odoo discuss channel. Multi-robot management, user binding, whitelist/blacklist, evaluation training, sync/async mode, sensitive words filter.

完整功能列表 / Complete Feature List

  • 1. 多ChatGPT OpenAI机器人连接器，支持对话与训练
    Multi ChatGPT OpenAI robot connector. Chat and train.
  • 2. 多AI支持：ChatGPT-4o、GPT-4 32k、GPT-3.5 Turbo、Azure AI、阿里通义千问、百度文心、DeepSeek
    Multi AI: ChatGPT-4o, GPT-4, GPT-3.5, Azure, Alibaba Qwen, Baidu, DeepSeek.
  • 3. 绑定AI机器人到用户，支持私聊或群聊频道
    Bind AI robot to user for private chat or AI channel for group chat.
  • 4. AI访问黑白名单控制
    White and black list for AI access control.
  • 5. 为新用户设置体验对话时间
    Setup demo chat time for every new user.
  • 6. 轻松启动和停止AI机器人
    Easy start and stop AI robots.
  • 7. 评价AI回复质量持续优化训练
    Evaluation AI responses for training improvement.
  • 8. 连接Microsoft Azure OpenAI服务
    Connect Microsoft Azure OpenAI Service.
  • 9. 支持同步或异步AI响应模式
    Synchronous or asynchronous mode for AI response.
  • 10. 敏感词过滤
    Sensitive words filter.
