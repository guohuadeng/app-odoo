Overview

This module is an AI center for Odoo, integrating multiple AI models (ChatGPT-4o, GPT-4, GPT-3.5, DeepSeek, Alibaba Qwen, Baidu AI, Azure OpenAI). Chat with AI robots directly in Odoo discuss channels, with multi-robot management, user binding, whitelist/blacklist, evaluation training, sync/async mode, and sensitive words filter.

Bring AI assistants into daily ERP work: ask questions in any discuss channel.
