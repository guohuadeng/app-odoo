Odoo 20 Enterprise & Community Multi-Company Multi-Language

Overview

User and developer documentation inside Odoo, with one-click access to the help of the screen you are working on. Documents can carry your company name and logo, the documentation server address is configurable, and MRP, Sales, Purchase, Stock and Accounting documentation is included. A systray icon gives quick access, and the app kanban menu has a View Help action.

Comprehensive Odoo user and developer documentation accessible in-app with one click. Features local branding with company logo, configurable documentation server URL, and covers all Odoo modules including MRP, Sales, Purchase, Stock, and Accounting. The systray icon provides instant help access, and the module kanban dropdown offers a "Help on Topic" action.
