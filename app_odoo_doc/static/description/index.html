Overview

Comprehensive Odoo user and developer documentation accessible in-app with one click. Features local branding with company logo, configurable documentation server URL, and covers all Odoo modules including MRP, Sales, Purchase, Stock, and Accounting. The systray icon provides instant help access, and the module kanban dropdown offers a "Help on Topic" action.
