核心亮点

一键访问Odoo文档，自有品牌，全模块覆盖

1. 用户与开发文档 / User & Developer Docs

Odoo Documentation

提供Odoo用户手册与开发人员文档，涵盖所有核心模块，随时查阅。

2. 一键当前主题帮助 / 1-Click Context Help

Instant Topic Help

系统托盘图标一键访问当前操作主题、当前菜单的帮助文档，即时解决问题。

3. 自有品牌文档 / Local Branding

Company Logo & Name

文档页面显示您的公司名称和Logo，完全可本地化，打造专属品牌体验。

4. 全模块文档合一 / All-in-One Docs

MRP, Sale, Purchase, Stock, Account

集生产制造、销售、采购、库存、财务等全部模块文档于一体，一站式查阅。

5. 可配置文档服务器 / Configurable Doc URL

Self-hosted or Remote

可配置文档主域名，在自有服务器托管文档或使用odooai.cn远程文档，灵活部署。

6. 模块看板帮助入口 / Kanban Help Action

Quick Access from Module List

模块看板下拉菜单提供"查看当前帮助"操作，从应用列表直接访问对应文档。
