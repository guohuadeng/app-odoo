核心亮点

many2one 字段父子树控件

1. 父子树结构

在 many2one 字段中显示库存位置的父子树结构

2. 多视图支持

支持列表和看板视图中的树状导航

3. 易于配置

可自定义展开层级、记录限制、排序方式

4. 完全开源

基于 LGPL-3 协议开源，支持二次开发

多语言与多公司

完整的多语言翻译支持，适配全球化企业部署。原生多公司架构，数据严格隔离。
