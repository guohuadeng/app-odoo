功能概述 / Overview

本模块是 odooai.cn 所有应用的核心基础模块，提供通用工具函数和面板。包含 Excel 快速导入、M2O 默认值、UTC 时区转换、浏览器 UA 获取、图片转本地附件、定时任务日志管理、邮件性能优化、自定义 RNG、距离计算等。

Core utility module for odooai.cn apps. Quick Excel import, M2O default value, UTC timezone convert, browser UA parser, image to local attachment, cron log management, mail boost, custom RNG, distance calculation.
