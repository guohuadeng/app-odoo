Overview

The shared foundation for odooai.cn apps. It provides fast Excel import, Many2One default helpers, UTC-to-local conversion, browser user-agent lookup, image and media to attachment, cron job logging, reducing useless mail, custom .rng files and small helpers such as distance between two points. It also improves the user access-rights form: a privilege with a single group renders as an independent checkbox, while a privilege with multiple groups keeps the native mutually exclusive dropdown. Load it through server_wide_modules.
