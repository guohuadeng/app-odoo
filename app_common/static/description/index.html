Overview

This is the core utility module for all odooai.cn apps. It provides common tools and panels: quick Excel import, M2O default values, UTC timezone conversion, browser UA parsing, image to local attachment, cron log management, mail performance boost, custom RNG and distance calculation.

Install it as a shared dependency base for odooai.cn app suites.
