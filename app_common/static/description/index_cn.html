把重复的工具代码收敛到一个基础模块：数据导入、时区转换、媒体本地化、定时任务与权限组件增强。

Odoo 20企业版与社区版多公司多语言

功能概述

本模块是 odooai.cn 系列应用的公共底座，提供 Excel 快速导入、Many2One 默认值、UTC 本地时区转换、浏览器 User-Agent 获取、图片与媒体转附件、定时任务日志、无用邮件抑制、.rng 文件自定义以及两点距离等常用工具。还增强了用户权限表单：权限范围仅含一个权限组时显示为独立复选框，多个权限组时保持原生互斥下拉。建议通过 server_wide_modules 加载。
