功能概述

本模块为 Odoo 活动模块（Event）添加 Superbar 树状搜索面板。在活动列表中，可按活动阶段（Stage）和标签分类（Tag Category）进行树状导航，快速筛选和浏览活动。同时支持多公司维度筛选。
