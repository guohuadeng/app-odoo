功能概述 / Overview

本模块为 Odoo 活动模块（Event）添加 Superbar 树状搜索面板。在活动列表中，可按活动阶段（Stage）和标签分类（Tag Category）进行树状导航，快速筛选和浏览活动。同时支持多公司维度筛选。

This module adds Superbar tree navigator to the Odoo Event module. Browse events by stage and tag category with parent-children tree in list, kanban, pivot, graph, and calendar views. Also supports multi-company filtering.
