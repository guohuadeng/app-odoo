功能概述 / Overview

本模块为 Odoo 集团公司提供多层级树状结构图（zChart）。通过交互式父子树可视化展示公司层级关系，支持批量设置上级公司向导。

This module provides a multi-level hierarchy chart (zChart) for group companies. Visualize company structure with interactive parent-children tree, and batch set parent company via wizard.
