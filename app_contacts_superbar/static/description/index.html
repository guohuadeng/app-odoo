功能概述 / Overview

为 Odoo 通讯录模块提供强大的侧边栏超级导航功能，支持按公司、合作伙伴类别、行业等多维度树状浏览联系人。在列表、看板、数据透视和图表视图中均可使用。

Provides a powerful sidebar superbar navigator for the Contacts module, enabling hierarchical browsing of partners by company, category, and industry across list, kanban, pivot and graph views.
