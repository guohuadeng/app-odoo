Overview

This module adds a tree navigator (Superbar) to Odoo Accounting. Browse journals, entries, journal items and analytic lines by account chart or analytic account hierarchy. It works with list, kanban, pivot and graph views, supports Ctrl/Cmd multi-select, and lets you include or exclude child node data with a checkbox.

Search across multiple fields, filter by tree nodes, and drill into accounting data from any view.
