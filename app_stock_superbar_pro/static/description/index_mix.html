功能概述 / Overview

库存高级搜索栏专业版在标准版基础上增加了日期范围搜索、即时和延迟两种搜索模式，支持调拨单、批次调拨、库存移动和移动线等视图的树状导航。

Stock Superbar Pro adds date range search and instant/lazy search modes on top of the standard version, supporting tree navigation across picking, batch, move and move line views.
