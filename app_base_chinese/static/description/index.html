Overview

This module provides comprehensive Chinese localization for Odoo with 20+ enhancements: Chinese address format, default country/timezone/currency, customer abbreviation and code priority display, category and warehouse location Chinese name fixes, YYYY-MM-DD date format, country sorting with China first, and policy-sensitive naming (Country to Country/Region). Works best with the Chinese translation pack from www.odooapp.cn.

Covers base, account, sale and stock models, install and it works.
