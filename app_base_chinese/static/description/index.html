Overview

A complete Chinese localization pack for Odoo with more than 20 adjustments: Chinese address format, default country, timezone and currency, partner abbreviation and code priority, Chinese names for product categories and warehouse locations, YYYY-MM-DD dates, China ranked first in country lists, and policy-sensitive country naming. It works best together with the Chinese translation pack from www.odooapp.cn.

This module provides comprehensive Chinese localization with 20+ enhancements: Chinese address format, default country/timezone/currency, customer abbreviation display, category and warehouse location Chinese name fix, date format YYYY-MM-DD, country sorting, policy-sensitive naming (Country→Country/Region). Best used with Chinese translation pack.
