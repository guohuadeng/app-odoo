功能概述 / Overview

本模块为 Odoo 提供全面的中文本土化增强，包含 20+ 项优化：中国地址格式、默认国家/时区/货币、客户简称与编码优先显示、品类和仓库位置中文目录名显示修复、日期格式年月日、国家排序中国第一、政策敏感词处理（国家→国家/地区）等。配合 www.odooapp.cn 的中文翻译包使用效果最佳。

This module provides comprehensive Chinese localization with 20+ enhancements: Chinese address format, default country/timezone/currency, customer abbreviation display, category and warehouse location Chinese name fix, date format YYYY-MM-DD, country sorting, policy-sensitive naming (Country→Country/Region). Best used with Chinese translation pack.

    Chinese address format for all customers, suppliers, partners, users, employees.

    Default values: country, timezone, currency. Processing module base, product.

    Display phone numbers along with mobile numbers for customer addresses.

    Currency processing with added sorting display.
  • 6. 修正品类列表及m2o字段中不显示中文目录名的Bug
    Fixed bug where category list and m2o field did not display Chinese name.

    Fixed bug where warehouse location list and m2o field did not display Chinese name.

    Superuser changed timezone to China.

    Country sorting added; China ranked first.

    Default export translation set to Chinese (po).

    Added name_en_US field in base model which updates translation value.

    Common decimal precision adjustments.

    Sales team changed to China.

    Simplified Chinese language display.

    Correct "Country" to "Country/Region" for policy sensitivity.
