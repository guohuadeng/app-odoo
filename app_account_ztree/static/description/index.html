Enable with a single widget attribute, configurable via XML parameters

Odoo 18 Enterprise & Community Multi-Company Multi-Language

Overview

This module provides a parent-children hierarchy tree widget (zTree) for Account Chart. Enable with widget='ztree_select', configurable with ztree_parent_key, ztree_expend_level, limit, order parameters. Reusable for any parent-child relationship model.

Works for product categories, stock locations, departments and any model with parent-child relations.
