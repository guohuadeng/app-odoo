功能概述 / Overview

本模块为会计科目提供多层级父子树状选择器（zTree widget）。通过 widget='widget_select' 即可启用，支持 ztree_parent_key、ztree_expend_level、limit、order 等参数配置。可复用于任何父子关系模型，如产品分类、库存位置、部门等。

This module provides a parent-children hierarchy tree widget (zTree) for Account Chart. Enable with widget='widget_select', configurable with ztree_parent_key, ztree_expend_level, limit, order parameters. Reusable for any parent-child relationship model.
