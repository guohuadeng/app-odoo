多层级会计科目树

会计科目父子层级树状选择器

基于 zTree 控件为会计科目提供多层级父子树状选择，支持列表和看板视图
一个 widget 属性即可启用，XML 参数灵活配置

Odoo 18 企业版与社区版 多公司 多语言

功能概述

本模块为会计科目提供多层级父子树状选择器（zTree widget）。通过 widget='ztree_select' 即可启用，支持 ztree_parent_key、ztree_expend_level、limit、order 等参数配置。可复用于任何父子关系模型，如产品分类、库存位置、部门等。

适用于产品分类、库存位置、部门等任何父子关系模型。
