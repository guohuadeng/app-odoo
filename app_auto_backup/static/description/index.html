功能概述 / Overview

本模块为 Odoo 提供完整的数据库自动备份解决方案。支持定时任务（cron）自动备份、远程 SFTP 加密传输备份、一键手动备份、备份文件下载与管理、连接测试、备份失败邮件通知、自动清理过期备份。

This module provides a complete database auto-backup solution for Odoo. Supports cron scheduled backups, remote SFTP encrypted backup, one-click manual backup, backup file download/management, connection testing, failure e-mail notification, and auto cleanup of old backups.

  • 2. 设置远程SFTP备份和定时计划
    Set remote SFTP backup and cron schedule.
  • 3. 一键手动备份数据库
    Manual backup database in one click.
  • 4. 系统用户可直接下载或删除备份文件
    Easy download backup file or remove file for System user.
