Product English Name Mixin

Maintain product English names with a reusable Mixin

Add a standard English name field to products, resolved by user language, with Chinese and English names coexisting.

Odoo 20Enterprise & CommunityMulti-CompanyMulti-Language

Overview

This module provides a reusable abstract Mixin (mixin.name.en) that adds a name_en_US field to any inheriting model. Writing the English name syncs it into the translatable name field under the en_US context, so English users see the English name while Chinese users keep the Chinese name. Product templates (SPU) are implemented out of the box, useful for export quotations, customs declarations and international websites. Enable the English language before installing.
