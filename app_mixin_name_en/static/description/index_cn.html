产品英文名 Mixin

用一个 Mixin 为产品自动维护英文名称

给产品增加标准英文名字段，按用户语言自动取值，中文名与英文名并存不冲突。

Odoo 20企业版与社区版多公司多语言

功能概述

本模块提供可复用的抽象 Mixin（mixin.name.en），为继承它的模型增加 name_en_US 字段。写入英文名时，会以 en_US 上下文同步到可翻译的 name 字段；用户语言为英文时显示英文名，中文界面仍显示中文名。产品模板（SPU）已内置实现，适合出口报价、报关与国际网站展示。安装前需在系统中启用英文语言包。

核心亮点

用一个 Mixin 为产品自动维护英文名称

1. Mixin 复用

任何模型继承即可获得英文字段

2. 英文名字段

为产品维护标准英文名称

3. 语言自动切换

按用户语言显示中英文名称

4. 无需改表结构

基于翻译字段同步，不增加冗余表

5. 安装前检查

未启用英文语言时阻止安装

完整功能列表

本模块包含的全部功能

  • 1. 抽象 Mixin，为任意模型增加英文名字段
  • 2. 写入英文名时自动同步到 en_US 翻译
  • 3. 中英文名称并存，按用户语言显示
  • 4. 产品模板（SPU）开箱即用
  • 5. 安装前校验英文语言包是否启用
